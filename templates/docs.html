Общие сведения

Программа предназначена для управления лазерным сканирующим конфокальным микроскопом и сбора экспериментальных данных. Поддерживаются следующие типы измерений:

  • спектры люминесценции;
  • спектры оптически детектируемого магнитного резонанса (ОДМР);
  • двух- и трёхмерные карты распределения люминесценции;
  • топографические карты поверхности.

Дополнительно реализовано исполнение управляющих программ в формате G-кода, что позволяет использовать микроскоп для задач лазерной литографии и субтрактивной обработки материалов.

Визуализация данных обеспечивает интерактивное управление отображением: масштабирование, панорамирование, вращение трёхмерных сцен, настройку цветовых карт и динамическое изменение отображаемого диапазона.

Обработка данных выполняется через нодовый редактор. Доступны алгоритмы фильтрации, нормализации, статистического анализа, геометрических преобразований и деконволюции с использованием функции рассеяния точки (PSF) оптической системы.

Поддерживаемое оборудование

Программа не привязана к конкретным моделям устройств. При наличии документации на протокол обмена могут быть подключены приборы следующих категорий:

  • двухкоординатные отклоняющие системы (сканеры пучка);
  • трёхкоординатные позиционеры предметного стола;
  • детекторы оптического излучения;
  • монохроматоры;
  • генераторы СВЧ-сигналов.

Настройка протоколов выполняется через конфигурационные файлы и сборщик команд. Модификация исходного кода не требуется.

Установка и первый запуск

Программа поставляется в виде архива. Для установки:

  1. Распакуйте архив в выбранную директорию.
  2. Запустите Confocal Soft.exe.

При первом запуске в папке service_files/ автоматически создаётся структура конфигурационных файлов со значениями по умолчанию.

Главное окно

При запуске восстанавливается последнее использовавшееся окно. Основные элементы главного окна:

  • Строка меню — доступ к общему функционалу программы.
  • Панель состояния интерфейсов — индикация подключённых устройств и их статуса.
  • Панель сообщений — вывод информационных сообщений и ошибок.
  • Строка статуса — текущее активное окно или выполняемая задача.

Переключение между окнами

Выполняется одним из способов:

  • через меню «Окно» — выбор нужного окна из списка;
  • горячими клавишами (комбинации указаны в соответствующих разделах руководства).

Режимы сканирования

  1. Комбинированное сканирование. Перемещение по X и Y выполняется сканером пучка; по Z — позиционером предметного стола. Обеспечивает высокую скорость в плоскости XY при ограниченном угле отклонения сканера.
  2. Сканирование позиционером. Все три координаты (X, Y, Z) отрабатываются позиционером стола. Позволяет сканировать большие области и исключает аберрации, связанные с отклонением пучка.

Параметры сканирования

Параметр Описание
Начальные координаты X₀, Y₀, Z₀ Точка начала области сканирования
Конечные координаты X₁, Y₁, Z₁ Точка конца области сканирования
Шаг dX, dY, dZ Расстояние между соседними точками по каждой оси
Время накопления Время регистрации сигнала в точке

Оценка времени сканирования

Полное время сканирования:

T = Nₓ · Nᵧ · N_z · (t_accum + t_losses)

где Nᵢ = ⌊(X₁ᵢ - X₀ᵢ) / dᵢ⌋ + 1 — число точек по оси; t_accum — время накопления; t_losses — накладные расходы на одну точку.

Накладные расходы включают: время передачи команды устройству, время приёма ответа, задержки операционной системы.

Повторное сканирование выделенной области (ROI)

После завершения сканирования на изображении можно выделить прямоугольную область. Параметры сканирования автоматически обновляются под выделенную область. Это позволяет пересканировать интересующий участок с тем же или изменённым разрешением без повторного ввода координат.

Режимы отображения 3D

  • Воксельный (Voxel-based). Данные представлены трёхмерной сеткой вокселей. Воксель отображается, если его интенсивность превышает заданный порог.
  • Объёмный (Volumetric). Строится трёхмерное облако точек, каждой из которых назначены цвет и прозрачность в соответствии со значением интенсивности.

Для работы окна требуется поддержка OpenGL версии 3.2 или выше.

Просмотр срезов

Предусмотрен режим просмотра отдельных слоёв по оси Z. Навигация по слоям — ползунком или кнопками. Переход в режим срезов не препятствует возврату к трёхмерному отображению.

Режимы работы монохроматора

  • Пошаговый. Монохроматор останавливается на каждой длине волны, выполняется измерение детектором, затем переход к следующей позиции. Максимальная точность позиционирования.
  • Непрерывный. Монохроматор изменяет длину волны без остановки; детектор регистрирует сигнал на всём протяжении диапазона. Выше скорость, однако возможен сдвиг данных из-за инерции механизма.

Опорный спектр

Используется для коррекции фонового сигнала. Пользователь регистрирует опорный спектр (без образца или с эталоном) и сохраняет его. Все последующие спектры отображаются с вычитанием опорного. Применяется при измерениях поглощения и люминесценции.

Параметры ОДМР сканирования

Параметры аналогичны спектральному сканированию, но диапазон задаётся в МГц, а шаг соответствует перестройке частоты СВЧ-генератора.

Случайный режим

При длительных измерениях возможен локальный перегрев образца в точке резонансного поглощения. Для предотвращения этого эффекта частоты перебираются не последовательно, а в псевдослучайном порядке. Тепловая нагрузка распределяется равномерно по диапазону.

Структура данных

  • Ветвь — соответствует одному эксперименту. Содержит общие параметры: комментарий, время создания, описание.
  • Лист — единичное измерение внутри ветви (матрица скана, спектр). Может быть визуализирован или экспортирован независимо.

При завершении измерения данные автоматически помещаются в дерево как новый лист. Ветвь для размещения определяется автоматически по совпадению параметров эксперимента.

Создание интерфейса связи

Программа поддерживает интерфейсы Serial и Ethernet. Для создания нового интерфейса:

  1. Меню «Настройки» → «Соединение».
  2. Кнопка «+ Добавить» → выбор типа интерфейса.

Параметры Serial

  • Порт — идентификатор (COM1, COM2, ...)
  • Скорость передачи — бод
  • Длина слова — обычно 8 бит
  • Чётность — None, Even, Odd, Mark, Space
  • Стоп-биты — 1; 1,5; 2
  • Таймаут отправки/ответа — время ожидания ответа, с

Параметры Ethernet

  • IP-адрес устройства
  • Порт — TCP-порт (обычно 502 для Modbus TCP)
  • Таймаут соединения
  • Таймаут отправки/ответа

Добавление устройства

Поддерживаются пять групп устройств: сканеры пучка, детекторы, позиционеры, монохроматоры, СВЧ-генераторы.

Групповые параметры

  • Сканеры пучка: Пределы отклонения, коэффициенты пересчёта LSB → мкм, коэффициенты компенсации гистерезиса.
  • Детекторы: Время накопления, период опроса, уровень компаратора.
  • Монохроматоры: Скорость протяжки, ускорение, токи удержания, число шагов на 1 нм.
  • Позиционеры: Рабочая область, коэффициенты пересчёта, ускорение.
  • СВЧ-генератор: Рабочий диапазон частот, выходная мощность.

Сборщик команд

Сборщик команд позволяет настроить протокол обмена без правки исходного кода. Настраиваются как отправляемые, так и принимаемые команды.

Бинарный формат

Настраиваемые блоки пакета: стартовое слово, адрес устройства, код команды, поле длины, конечное слово, контрольная сумма, данные.

ASCII-формат

Настраиваются: префиксы/суффиксы команд, разделители, терминатор фрейма, кодировка.

Принцип работы

Нодовый редактор предназначен для построения конвейеров обработки данных. Пользователь соединяет функциональные блоки (ноды) в граф; данные передаются по соединениям, преобразуясь на каждом шаге.

Категории нод

  • DATA_IO: Загрузка из файлов, экспорт в файлы
  • MATH: Арифметические операции, нормализация, статистика
  • FILTERS: Сглаживание, шумоподавление, деконволюция
  • TRANSFORMS: Геометрические преобразования, выделение областей
  • AVERAGING: Простое, взвешенное, робастное усреднение
  • SEGMENTATION: Пороговая обработка, водораздел, k-means
  • VISUALIZATION: Гистограммы, отображение изображений
  • UTILS: Отладка, работа с метаданными

Параметры сохранения

  • Группировка в файл — все листы ветви сохраняются в один файл
  • Добавление даты/времени — префикс к имени файла
  • Включение заголовка — в файл данных добавляются заголовки столбцов
  • Открыть папку после сохранения — автоматическое открытие директории
