Технические требования

Минимальные требования

  • ОС: Windows 7 (64-bit)
  • ОЗУ: 2 ГБ
  • Место на диске: 500 МБ
  • OpenGL: 3.2 или выше (для 3D)
  • Видеоускоритель: Нет

Рекомендуемые требования

  • ОС: Windows 10 (64-bit)
  • ОЗУ: 16 ГБ
  • Место на диске: 5 ГБ SSD
  • OpenGL: 4.5 или выше (для 3D)
  • Видеоускоритель: Да

Основные возможности

2D Сканирование

Двухкоординатное сканирование образца с поддержкой комбинированного режима (сканер пучка + позиционер) и режима позиционера. Выбор режима определяется конфигурацией оборудования. Позволяет получать карты распределения интенсивности люминесценции с высоким разрешением.

3D Визуализация

Трёхмерная визуализация данных с воксельным и объёмным режимами отображения. Просмотр срезов по оси Z, вращение сцены, настройка цветовых карт и прозрачности. Требуется поддержка OpenGL 3.2 или выше.

Спектрометрия

Спектрометрические измерения с поддержкой пошагового и непрерывного режимов работы монохроматора. Автоматическое усреднение спектров, вычитание опорного спектра, настройка времени накопления и числа повторений.

ОДМР измерения

Оптически детектируемый магнитный резонанс с псевдослучайным режимом перебора частот для предотвращения локального перегрева образца. Управление СВЧ-генератором в диапазоне МГц.

G-код управление

Управление по G-коду для автоматических траекторий и лазерной обработки. Поддержка команд G00, G01, M03, M05, G04. Загрузка файлов .gcode, .nc, .txt и SVG с автоматической конвертацией.

Нодовый редактор

Обработка данных без написания кода. Визуальное программирование конвейеров обработки: фильтрация, нормализация, статистический анализ, геометрические преобразования, деконволюция с PSF.

Экспорт данных

Сохранение результатов в форматах: CSV, HDF5, NPY, TIFF, JSON и других. Гибкая настройка параметров сохранения, группировка в файл, добавление метаданных.

Гибкая настройка

Поддержка Serial и Ethernet интерфейсов. Настройка протоколов обмена через сборщик команд без правки исходного кода. Бинарный и ASCII форматы.

Поддерживаемое оборудование

Двухкоординатные отклоняющие системы (гальвосканеры)

Устройства для отклонения лазерного пучка по двум осям. Обеспечивают высокую скорость сканирования при ограниченном угле отклонения. Настройка пределов отклонения, коэффициентов пересчёта LSB в микрометры, компенсация гистерезиса и люфта.

Трёхкоординатные позиционеры предметного стола

Пьезоподвижки и столы на шаговых двигателях для перемещения образца по осям X, Y, Z. Обеспечивают высокую точность позиционирования. Настройка рабочей области, коэффициентов пересчёта и ускорения.

Детекторы оптического излучения

Фотодиоды, счётчики фотонов и синхронные детекторы для регистрации оптического сигнала. Настройка времени накопления, периода опроса и уровня компаратора для детекторов, работающих в режиме счёта отдельных событий.

Монохроматоры

Спектральные приборы для выделения узкого диапазона длин волн из широкополосного излучения. Настройка скорости протяжки, ускорения, токов удержания и числа шагов двигателя на 1 нм.

Генераторы СВЧ-сигналов

Источники электромагнитного излучения СВЧ-диапазона для возбуждения магнитного резонанса в образцах. Настройка рабочего диапазона частот и выходной мощности.
